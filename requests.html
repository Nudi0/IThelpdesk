Reset Your Password

Step-by-step guide to reset your network or application password via the self-service portal.

  • Visit portal.company.com/reset
  • Enter your Employee ID and registered email
  • Follow the link sent to your inbox
  • Set a new password (min 10 chars, 1 symbol)
🌐

Connect to VPN

How to securely connect to the company network from home or a remote location.

  • Open Cisco AnyConnect from your taskbar
  • Server: vpn.company.com
  • Log in with your network credentials
  • Accept the push notification on your phone
🖨️

Set Up a Printer

Add a network printer to your Windows or Mac workstation in a few simple steps.

  • Go to Settings → Printers & Scanners
  • Click Add a printer or scanner
  • Select your floor printer from the list
  • Install driver if prompted (auto via Windows Update)
📧

Configure Outlook Email

Set up your company email account in Microsoft Outlook on desktop or mobile.

  • Open Outlook → File → Add Account
  • Enter your company email address
  • Outlook auto-discovers settings — click Connect
  • Authenticate with your network password + MFA
🐢

My Computer Is Running Slow

Quick troubleshooting steps before you raise a hardware or software ticket.

  • Restart your machine (not just sleep)
  • Close unused applications and browser tabs
  • Run Disk Cleanup from the Start menu
  • Check Task Manager for high CPU / memory processes
📦

Request New Software

The process for requesting a new application to be installed on your workstation.

  • Check the Approved Software List on the intranet first
  • Submit a ticket with category Software
  • Include a business justification
  • Allow 3–5 business days for IT review and installation
